# PlanPacer

> Understand your time. Shape your life.

PlanPacer is a web application for logging activities and visualizing how you actually spend your time.

## What is it?

PlanPacer is not a to-do app.

It is a **time logging and life analytics tool** that helps you answer questions like:

- Where did my day go?
- How much time did I spend gaming?
- Am I spending enough time studying?
- What patterns do I repeat every week?

---

## Features

- 📝 Log activities quickly
- 📅 Daily timeline view
- 📊 Statistics and reports
- 🏷️ Categories and activity details
- 📱 Works on desktop and mobile
- ☁️ Data stored online and accessible anywhere
